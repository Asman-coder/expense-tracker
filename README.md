# 💰 Personal Expense Tracker - Python

A simple CLI-based expense tracker to manage daily expenses. Built with Python and CSV for data storage.

## 🚀 Features
- Add new expenses (date, category, amount)
- View all expenses
- Auto-saves to CSV file
- Category-wise tracking

## 🛠️ Tech Used
- Python 3
- CSV modul
python expense
